
# Society Management Platform

A full-stack residential society management platform built using Java, Spring Boot, React, and PostgreSQL.

## Planned Features

- Society, building, wing, and flat management
- Resident and staff management
- Visitor entry and exit tracking
- Complaint and maintenance management
- Announcements and notifications
- Role-based access control
- Parking and vehicle management
- Camera access management

## Technology Stack

- Java 21
- Spring Boot
- React and Vite
- PostgreSQL
- Git and GitHub

## Project Status

Initial setup. Development will proceed incrementally, with testing and documentation at each stage.
